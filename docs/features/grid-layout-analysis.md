# 网格布局与多窗口适配分析

Readest 支持在同一个窗口内同时打开多本书籍（多标签页/分屏模式），其核心布局逻辑由 `BooksGrid` 和 `grid.ts` 驱动。

## 1. 动态网格响应 (`getGridTemplate`)

系统不依赖 CSS Grid 的 `auto-fill` 或 `auto-fit`，而是使用确定性的计算逻辑来保证多书同屏时的阅读体验。

- **输入**: 打开的书籍数量 (`count`)，窗口长宽比 (`aspectRatio`).
- **策略**:
  - **单本书**: 占满全屏 (`1fr`).
  - **两本书**:
    - 横屏 (Ratio > 1): 左右分屏 (`1fr 1fr`).
    - 竖屏 (Ratio < 1): 上下分屏 (`1fr / 1fr`).
  - **三/四本书**: 强制 2x2 网格 (`1fr 1fr / 1fr 1fr`).
  - **五本及以上**: 强制 3x3 网格（极少使用场景）.

## 2. 安全区与边距 (`Insets`)

在多屏模式下，为了避免刘海屏遮挡或视觉拥挤，系统需要精细控制每个格子的内边距。

- `getInsetEdges`: 计算每个格子是否处于网格的边缘（上/下/左/右）。
- **逻辑**: 只有处于网格边缘的格子侧边，才会应用系统的安全区边距（如 `screenInsets.top`）。内部相邻的边距设为 0，从而实现无缝拼接效果（或仅保留分割线）。

## 3. UI 适配

`BooksGrid.tsx` 会遍历所有打开的 `bookKeys`，为每个阅读器实例 (`FoliateViewer`) 分配一个 `div` 容器，并动态设置 `gridTemplateColumns` / `gridTemplateRows`。这种设计使得 Readest 在 iPad 分屏或桌面窗口调整大小时，能平滑地重排书籍布局，保持阅读内容的最佳显示比例。
