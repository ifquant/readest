# 简繁体转换功能分析

Readest 为中文用户提供了内置的简繁体实时转换功能，无需修改原始电子书文件即可改变阅读体验。

## 1. 转换层级

该功能通过多个切面（Transformers）切入渲染流程：

### 1.1 正文文本 (`simplecc.ts`)

这是一个基于 `TextNode` 的 Transformer。

- **操作**: 遍历 DOM 树中的所有文本节点。
- **逻辑**: 调用 `runSimpleCC(text, variant)` 将文本内容即时替换。
- **性能**: 因为只操作 DOM 节点的内容而不改变结构，且转换库（通常是 OpenCC 的精简版）经过优化，对渲染性能影响极小。

### 1.2 目录与元数据 (`toc.ts`)

目录 (Table of Contents) 通常独立于正文渲染。

- `convertTocLabels`: 递归遍历目录树，将章节标题 (`label`) 进行同构转换，确保侧边栏导航与正文语言一致。

### 1.3 标点符号 (`punctuation.ts`)

这是一个高级特性。简繁体不仅仅是汉字的差异，标点习惯也不同（例如简体的弯引号 `“` `”` 与繁体的直角引号 `「` `」`）。

- **自动适配**: 当开启简转繁 (`s2t`, `s2tw`) 时，系统可自动应用标点转换规则。
- **逻辑**: `shouldReverse` 标志位用于判断是否需要反转映射方向。

## 2. 转换变体 (`ConvertChineseVariant`)

系统支持多种转换模式，通常直接映射到 OpenCC 的标准配置：

- `s2t` / `t2s`: 标准简繁互转。
- `s2tw` / `tw2s`: 台湾正体标准。
- `s2hk`: 香港繁体标准。

## 3. 实现细节

核心转换函数 `runSimpleCC` 封装了具体的字库映射。在 Web 端，这可能通过加载轻量级的 Trie 树或 Map 实现。该设置是**实时生效**的 (`LangPanel.tsx` 中状态变更即触发重渲染)，且只影响显示层，不会修改书籍源文件。
