# TradeBlazer编译器功能测试计划

## 概述

本测试计划旨在系统性地测试TradeBlazer编译器的各个核心功能，确保其正确实现了脚本语言的设计要求，特别是变量声明和使用的限制。

## 测试分类

### 1. 变量声明和使用测试
- 测试在脚本开头声明的全局变量是否可以在函数内正常使用
- 测试在函数内声明局部变量是否会被正确阻止
- 测试变量重复定义

### 2. 序列(series)变量测试
- 测试序列变量的创建和更新
- 测试序列变量的长度限制
- 测试在函数内声明序列变量是否会被正确阻止

### 3. 函数测试
- 测试函数定义和调用
- 测试函数参数传递
- 测试函数嵌套定义是否会被正确阻止
- 测试TradeBlazer标准函数(OnInit, OnBar, OnTick)的处理

### 4. 表达式和运算符测试
- 测试算术运算符
- 测试比较运算符
- 测试逻辑运算符
- 测试复合赋值运算符

### 5. 控制流测试
- 测试if/else条件语句
- 测试for循环
- 测试在函数内声明循环变量是否会被正确阻止

### 6. 内置函数和指标测试
- 测试Print函数
- 测试交易指令函数(Buy, Sell等)
- 测试技术指标(Close, High, Low等)

### 7. 注释测试
- 测试行注释和块注释的支持

## 测试文件结构

每个测试对应一个 Rust 示例程序，该程序会从 `support/script_sources.rs` 中读取内联脚本常量并执行。无需单独的 `.tb` 文件，脚本内容直接内置在源码中，便于维护与查阅。
